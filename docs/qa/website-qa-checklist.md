## P1：行動版與效能

### 需要真人實機測試（保留給之後）

- [ ] iPhone Safari：首頁、測驗、結果頁、文章、指南、教練頁沒有橫向捲動、文字截斷或固定按鈕遮擋。
- [ ] Android Chrome：同一組頁面與流程。
- [ ] 手指操作：所有主要 CTA、頁尾條款／隱私、回上頁、內容卡片均可點擊，不需放大畫面。
- [ ] 手機完成 24 題訪客測驗後重新整理，結果仍會顯示。
- [ ] 手機以 Google／Email 登入，結果會回到同一帳號的「我的 FACE」。
- [ ] 手機實測 LINE 登入：LINE 授權後能回到網站；以非開發者帳號測一次。這是 LINE Channel 設定驗收，與 Supabase 資料庫無直接因果關係。
- [ ] 從 LINE App 內建瀏覽器開啟網站，檢查登入與外連結行為；不要在測試中送出不必要的訊息。

## P2：跨流程、內容與可用性

- [ ] 測驗中返回、重新整理、關閉後重開：確認進度與結果的預期行為，沒有誤導性提示。
- [ ] 三個結果分頁同時登入：會員帳號只新增一筆結果（已在桌面生產環境驗收；建議日後改版再回歸測）。
- [ ] 已登入／未登入兩種狀態：文章、指南、會員頁與購買入口的權限文案一致。
- [ ] 快速連續開啟同一篇文章或開兩個分頁：閱讀進度只保留一筆、可合併最高進度，且不顯示「暫時無法儲存」錯誤。
- [ ] 所有「即將推出」影片與人格閱讀卡：不會導到空白頁，文案明確告知尚未開放。
- [ ] 生存指南 CTA：可到方案／早鳥頁；教練 CTA：可到教練介紹與 LINE 諮詢入口。
- [ ] 隱私權、服務條款、退款與資料刪除頁：連結可開啟、文字與實際流程一致。
- [ ] Chrome、Safari、Edge 最新版桌面各跑一次首頁、測驗、結果與一篇文章。

## P3：長期品質、無障礙與營運

- [ ] 鍵盤驗收：Tab 焦點看得見、Enter／Space 可操作按鈕、Esc 可關閉登入視窗。
- [ ] 螢幕閱讀器基本路徑：首頁主標、表單題目、錯誤訊息、載入狀態都有可理解的朗讀內容。
- [ ] 縮放至 200%：文字不重疊，核心流程仍可完成。
- [ ] 無痕視窗與清除網站資料後：訪客測驗、登入、結果保存仍依預期運作。
- [ ] Supabase 可用性事件：確認雲端暫停／網路失敗時，網站顯示瀏覽器暫存提醒，不假稱已保存。
- [ ] SEO：首頁、人格頁、文章頁以搜尋引擎檢查 title、description、canonical、Open Graph 與可索引性。
- [ ] 每月備份：從 Supabase 匯出資料庫備份，確認檔案可取得且保存位置受控。
- [ ] 隱私與資料生命週期：以測試帳號申請資料刪除，確認操作、通知與資料移除範圍符合公開說明。
