# FACE 人格圖鑑長文排版規格

目前狀態：PILD「樹懶思想家」為排版試行頁。確認後才套用其餘 15 型。

## 1. 閱讀順序

每個章節固定依照以下順序呈現：

1. 章節標記：告訴讀者目前位置，例如 `CHAPTER 03`。
2. 章節標題：一句話說明這一章談什麼。
3. 一句話導讀：說明這一章和讀者的交易有何關係。
4. 圖片與正文：圖片先建立情境，文字再解釋行為與心理。
5. FACE Tips／結論卡：只留下理解、判斷或可執行動作。

不在同一視窗內同時製造兩個主要標題。圖片上的既有文字不能與頁面標題競爭。

## 2. 字體角色

- 中文標題、正文與引文：`Noto Serif TC`。保持宋體的閱讀質感，字重以 400 為主。
- 英文、數字、章節編號、按鈕與操作標籤：`Noto Sans TC`。不使用等寬字體製造程式碼感。
- 英文與數字使用 lining／tabular numerals，確保章節編號與代碼排列整齊。
- 粗體不是主要強調工具；優先使用尺寸、留白、特殊色與底框建立層級。

## 3. 六個文字層級

| 角色 | 桌機／手機原則 | 用途 |
| --- | --- | --- |
| Chapter kicker | 12–13px、無襯線、字距 0.14em | CHAPTER、SCENE、FACE Daily |
| Chapter title | 30–40px、行高約 1.48 | 章節主標題 |
| Chapter deck | 17–21px、行高約 1.85 | 標題下的一句話導讀 |
| Body | 16.5–17.6px、行高 1.95–2 | 說明、分析與情境正文 |
| Supporting | 約 15.5px、行高 1.9 | 生活比喻、補充說明、註記 |
| Takeaway | 19–23px、行高約 1.82 | FACE Tips、結論與行動收束 |

正文單行建議控制在約 28–36 個全形中文字。過長段落應利用圖文欄、卡片內距或最大行長收斂，不以縮小字體解決。

## 4. 中文換行

- 使用嚴格中文換行規則，避免句首出現逗號、句號、冒號、右引號等標點。
- 標題使用平衡換行；正文使用自然段落換行，不硬插 `<br>`。
- 保留完整詞組，例如「交易人格」「自我覺察」「風險報酬」不應因窄螢幕被不自然拆散。
- 資料內容已含 `「」` 時，介面不可再包一層引號。
- 不使用 `overflow-wrap: anywhere` 強制拆解中文引文；只有網址或不可分割字串可以例外。

## 5. 色彩與背景

- 正文：深暖灰，避免純黑造成壓迫。
- 輔助文字：中暖灰，但不得低於可閱讀對比。
- 特殊色：低飽和磚紅，只用於關鍵句、章節標記與行動提示。
- 淺底段落：暖白與淡米色交替，差異只負責分段，不搶走文字注意力。
- 深底段落：必須使用專用反白角色；主標題接近白色，正文至少 90% 白，標記至少 78% 白。
- 同一張卡片最多只有一個主要底色與一個提示底色。

## 6. 圖文關係

- 手機：章節標題 → 圖片 → 文字 → 結論；不讓讀者先讀解釋、再回頭找圖。
- 桌機：依文字量調整圖文比例，短文讓圖片較大，長文讓文字欄較寬。
- 圖片負責呈現情境、動作或心理狀態；文字負責說明原因與下一步，兩者不重複同一句話。
- 圖片不能壓字，文字不能覆蓋在細節複雜的圖片上。
- 圖片與文字分欄時，兩側的視覺重量要平衡；不因固定 50/50 造成過多空白或文字擁擠。

## 7. 手機版驗收

- 360–430px 寬度下，不出現橫向捲動。
- 章節標題最多約三行，一句話導讀最多約四行。
- 正文不小於約 16.5px，操作文字不小於 13px。
- 可點擊項目高度至少 44px。
- 同一個手機畫面內，讀者能清楚分辨「現在在哪一章」與「下一個要讀什麼」。
- 圖片之後立即出現與它對應的文字，不插入不相干標籤。

## 8. 套用其他 15 型前的條件

- PILD 桌機與手機均完成視覺驗收。
- 深色背景、圖片卡、摺疊卡與結論卡都有固定角色可重用。
- 不再以新增臨時字級或顏色解決單一人格的問題。
- 新人格只替換內容與圖片，不改動六個文字層級和章節閱讀順序。
