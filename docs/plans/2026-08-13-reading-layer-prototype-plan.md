# FACE 閱讀層級 Prototype

## 目標

用單一人格與單一壓力場景，驗證保留原本完整內容時，能否透過手機優先的編排降低閱讀負擔。

## Prototype 範圍

- 人格：ARTC 獵豹狙擊手。
- 場景：條件成立後進場，但行情立刻失效。
- 保留原本十個段落的單一路徑，不拆成摘要／進階／完整三層。
- 不使用橫向章節導覽；讓每一章本身的標題與一句話自然帶入閱讀。
- 先校正手機版標題、內文、行距、留白與卡片層級，再延伸桌機排版。
- 只在壓力觸發等因果情境加入插圖，不用插圖裝飾抽象人格。
- 合併重複心理主題；每章必須提供新的理解、投資心理機制或可執行動作。
- 獨立路由：`/reading-prototype`，不替換正式人格圖鑑與每日覺察結果。

## 驗收

- [ ] 十個段落的章節標題與一句話描述都能快速辨認。
- [ ] 手機內文不需縮放，長段落仍有清楚的視覺停頓。
- [ ] 插圖能協助理解壓力情境，且不重複段落內容。
- [ ] 手機不橫向溢出，章節導覽可橫向瀏覽。
- [ ] `npm run typecheck` 與 `npm run build` 通過。
