# 股票套牢該停損還是續抱？先問自己這 4 個問題

股票套牢時，最危險的往往不是虧損。

而是你開始不敢問：我現在還留在這裡，到底是因為相信，還是因為不甘心？

剛買進時，你通常說得出理由。跌了一段後，理由容易慢慢變成一句：「都跌這麼多了。」

那不是理由。那是價格留下來的痕跡。

## 1. 如果今天空手，我還會用這個價格買它嗎？

這個問題很殘忍，卻很有用。

如果答案是不會，你要再問：我留著它，是因為新的判斷，還是因為不想承認原本買錯？

不願意賣，不等於有信念。有時候，只是沈沒成本太重。

## 2. 我當初相信的事情，還在嗎？

別只看股價。

回到你第一次買進時寫下的理由：你期待什麼？哪一件事讓你覺得值得等？現在那件事還在，還是已經改變？

[犀牛親衛隊](/types/PILC)很會守住相信的東西。這是優勢；但市場已經改變時，守護也可能變成把舊信念留在原地。

## 3. 我是等它回本，還是等原本的未來發生？

「回本就賣」聽起來合理，卻常讓人失去判斷。

市場不知道你的成本。它只會繼續走自己的路。

如果你等的是回本，請承認你現在處理的是情緒；如果你等的是原本的未來，請說清楚未來還有哪些證據。

## 4. 留著它，讓我還做得出其他決定嗎？

[樹懶思想家](/types/PILD)很能等待。但等待的前提，是你仍有能力抬頭看市場，而不是把帳戶關掉，假裝事情沒有發生。

一筆部位如果讓你睡不好、無法看其他機會、也不敢重新檢查理由，它佔用的不只資金，還有判斷力。

套牢時不必急著做出最漂亮的決定。先把這四題寫下來。當你能重新把理由說清楚，停損或續抱才會變成選擇，而不是硬撐。
