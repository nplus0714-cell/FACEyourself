# 看了很多消息，反而更不敢下單怎麼辦？

## 0:00–0:20｜開場

**口播：**

你看的消息愈多，心裡反而愈亂。

看完新聞、財報、法說和社群，最後不是更有把握。

是更不敢下單。

很多時候，問題不是資訊不夠。

你是在等一個能替你承擔結果的答案。

**字幕：** 你想找的，可能不是消息。

## 0:20–1:05｜為什麼愈看愈焦慮

**口播：**

下單以後，市場不一定照你的想法走。

這件事沒有人能替你保證。

所以我們會一直找資料，希望再看一篇，就能少一點不確定。

可是資料愈多，反方理由也愈多。

最後你不是更會判斷。

你只是把做決定的時間往後拖。

## 1:05–1:45｜人格畫面

**口播：**

[鱷魚精算師](/types/PRTC)想把每個風險算清楚。

這讓他少犯很多錯。但壓力大時，他也可能把「還沒算完」誤認成「不能開始」。

[鼴鼠導引者](/types/PRLD)擅長準備。

他有時真正需要的，不是再多一份資料，而是在資訊夠用時跨出很小的一步。

## 1:45–2:30｜三件事

**畫面：** 三張短字卡。

**口播：**

一筆交易，不需要等到所有人都同意。

先留下三件事：我看見了什麼、我為什麼願意做、什麼發生後要重看。

它們不是用來保證你正確。

它們讓你以後可以回頭看：我是依照判斷行動，還是被消息帶著走？

還有一件事更重要。

決定今天不再看什麼。

不在下單前刷社群。不反覆看同一則新聞。不把別人的目標價當成自己的答案。

## 2:30–3:15｜FACE CTA

**口播：**

FACE 測驗能幫你看見，你做決定時更需要理由、感覺、等待，還是動作。

你不需要把自己改成另一種交易者。

先知道自己需要多少證據才敢行動，才有機會建立做得出來的規則。

**字幕／按鈕：** 開始 FACE 交易心理測驗
