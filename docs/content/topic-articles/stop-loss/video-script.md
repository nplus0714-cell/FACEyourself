# 停損怎麼設，才不會一跌就被洗掉？

## 0:00–0:20｜開場

**畫面：** 近景口播，先不放圖表。

**口播：**

停損最難的地方，不是 5%、8%，還是 10%。

最難的是，價格一跌，你不知道自己是在保護本金，還是在放棄一個你其實還相信的未來。

所以很多人停損後覺得被洗掉。

不是因為數字不夠漂亮。

是因為離開的理由，從來沒有想清楚。

**字幕：** 停損不是數字，是理由。

## 0:20–1:00｜兩種離開

**畫面：** 交易筆記、盤勢波動、賣出確認畫面。

**口播：**

有一種賣出，是你事前就知道：如果這個條件沒有出現，這筆交易就暫時不屬於我。

另一種賣出，是你撐到很不舒服，終於受不了。

兩種賣出，結果可能一樣。

心裡的感覺完全不同。

前者賣掉後，你知道自己在等什麼。

後者賣掉後，只要它漲回去，你就很容易想追回。

因為你不是不相信它。

你只是先輸給了壓力。

## 1:00–1:40｜不同人格，不同停損問題

**畫面：** 人格卡輕帶過；字幕顯示名稱。

**口播：**

[獵豹狙擊手](/types/ARTC)需要防的，是原本要等的加速沒有出現。

他的停損，是承認這一槍沒打中，不是說自己不會交易。

[白鹿鑑古師](/types/PRLC)需要防的，是把「我還相信」變成「我不願承認事情變了」。

他的停損，是回頭看：當初相信的東西還在嗎？

同樣叫停損。

有人在處理節奏，有人在處理信念。

先知道自己在處理什麼，才不會拿同一個數字處理所有交易。

## 1:40–2:25｜下單前寫一句話

**畫面：** 黑底字卡，再切筆記本。

**口播：**

下次下單前，不要先寫「跌到哪裡我要賣」。

先寫這一句：

如果 ______ 發生，我會知道原本的理由需要重看。

可以是走勢沒走出來。

可以是等待太久。

可以是你原本相信的條件改變。

這句話不會保證你不被洗掉。

它會讓你離開時，至少知道自己為什麼離開。

## 2:25–3:10｜FACE CTA

**畫面：** FACE 測驗情境題與結果頁局部。

**口播：**

有人太快停損，總覺得自己賣飛。

有人明明知道理由變了，還是很難離開。

如果你想知道壓力來時，自己比較容易太早放手，還是太晚承認，來做 FACE 交易心理測驗。

它不替你設停損。

它幫你先看見：每次最難按下賣出鍵時，到底是哪一種反應在拉住你。

**字幕／按鈕：** 開始 FACE 交易心理測驗

## 3:10–3:30｜收尾

**畫面：** 交易解憂 Bar。

**口播：**

現在不想測，也可以先來交易解憂 Bar 先喝一杯。

這裡聊停損、套牢、賣飛，還有那些你明明知道該做，卻很難真的做出來的事。

**字幕／按鈕：** 進入交易解憂 Bar
