# 投資飲料店的故事：讓資源留在會賺錢的地方

我很喜歡用投資飲料店來理解股票。

假設今天，你投資了兩家飲料店。第一家開了一段時間，客人一直沒有增加，收入起不來，每天還要繼續補錢。另一家卻慢慢開始排隊，營收增加，甚至有人開始問：「要不要開第二家？」

如果你真的在做生意，大概很自然會開始想：哪一家值得繼續投資？哪一家應該先停下來檢查？

你不會因為第一家已經投入很多錢，就無限把後面的資源全部塞進去；也不會因為第二家已經開始賺錢，突然說：「太好了，賺到了，我們把店關掉。」

但到了股票市場，很多人剛好完全反過來。

賺錢的股票，第一個念頭是：「先獲利了結。」賠錢的股票，反而開始想：「再買一點，成本可以降低。」

於是你一直把新的錢，放進一個還沒有證明自己的地方；而真正正在替你賺錢的部位，卻被一點一點賣掉。

我不是說上漲一定要加碼，也不是說虧損一定不能買。真正重要的，還是那家「店」現在有沒有繼續證明自己的價值。

客人真的增加嗎？商業邏輯還成立嗎？它有沒有持續替你創造價值？如果有，為什麼反而急著把它關掉？

投資飲料店的故事，真正想提醒的不是「永遠抱強勢股」，而是：**資源應該跟著驗證移動。**

不要一直餵養一個自己捨不得放棄的部位；也不要因為開始賺錢，就急著離開一個正在證明自己的機會。

真正的進攻，不只是學會找到機會。也要學會讓資源慢慢留在正在替你賺錢的地方。
