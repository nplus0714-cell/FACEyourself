# 交易是一輩子的事，所以要做得舒服

市場很喜歡一句話：**跨出舒適圈。**放在人生成長裡沒有什麼問題；但放在交易裡，我反而會多想一下。

你明明只能承受 10% 的部位，硬逼自己集中重壓，不一定叫成長。你明明不適合每天盯盤，卻逼自己做超短線，也不一定叫突破。

如果一套方法每天都讓你焦慮、讓你睡不好、讓你一直做出和平常完全不同的決定，那你很難靠意志力撐一輩子。

而我一直覺得：**交易是一輩子的事。**既然是一輩子的事，那就應該做得舒服一點。因為舒服，你才做得久。

我講的舒服，不是完全沒有壓力。市場不可能一直讓你舒服。你一樣會停損、會錯過、會看錯，也會看到原本很大的獲利突然縮水。

舒服比較像是：**即使市場正在讓你不舒服，你還是做得出原本會做的事情。**

該停損的時候，你還停得掉；該持有的時候，你還抱得住；真正屬於自己的機會出現，你還敢出手；完全看不懂的時候，你也能安心不做。

這就是我理解的交易舒適圈。

舒服不是市場不要波動，而是：**你的方法沒有一直逼你變成另外一個人。**

有人適合集中，有人需要分散；有人喜歡研究公司，有人更相信價格和規則；有人願意等很久，有人一段時間沒有結果，就會覺得資金效率太低。這些本來就可以不一樣。

真正值得問的，不是哪一種方式比較厲害，而是：**哪一種方式，我可以一直做？**

我覺得適合自己的交易方式，至少應該有幾個條件：

**你看得懂。你承受得了。你做得到。你願意一直重複。**

舒適圈不代表永遠不要進步。部位可以慢慢增加，持有時間可以慢慢拉長，新的方法可以慢慢學，原本不熟的市場也可以慢慢理解。

但順序很重要：**能力先長，部位再長。**而不是部位先長，再逼心態跟上。

先把原本做得到的事情做穩，慢慢累積經驗，讓舒適圈自然變大。這也是成長，只是沒有必要一次把自己推到最外面。

交易不是一次考試，不是今年一定要證明自己多厲害。只要你還願意留在市場，能力本來就可以慢慢長。

舒服不是偷懶，反而是：**替自己找到一個可以長期練習的位置。**
