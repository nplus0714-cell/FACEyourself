# 槓桿是給守紀律、有獲利的人用的

在討論槓桿以前，我想先問兩個問題。

如果你已經有能力賺錢，你為什麼想開槓桿？這不是暗示你一定應該開，只是希望你問自己：我要槓桿，到底是為了什麼？

反過來，如果你現在賺錢還不穩定，我更想問：那你為什麼急著現在就要開槓桿？

一套原本還沒有穩定的方法，加上槓桿以後，不會突然變成好方法；它只是讓原本的結果變得更大。

槓桿本身沒有善惡，就是工具。真正重要的是：誰在使用，以及怎麼使用。

它有一點像喝酒。喝酒本身不是問題；在適合的情況下，理性地喝一點，人可以很舒服。但喝酒再加上駕駛，就完全是另一件事情。槓桿也是一樣。

把槓桿和沒有停損、沒有紀律、沒有穩定方法、情緒失控放在一起，風險就完全不同。

如果一個人沒有停損紀律，不知道自己靠什麼賺錢，也還不知道遇到大波動時自己會怎麼反應，這時候再增加槓桿，只是把原本還沒有處理好的問題一起放大。

原本虧 5%，你就開始慌；槓桿不會讓你突然變冷靜，只會讓那個慌更快出現。

所以槓桿比較適合守得住紀律，而且已經證明自己有能力產生獲利的人。這不是因為這些人不會賠錢，而是增加速度以前，至少已經知道自己平常是怎麼開車的。

如果你已有一套方法，知道怎麼控制損失、知道什麼時候該退出，也累積一些好的持股替帳戶建立獲利墊，這時候再思考槓桿，問題才比較接近：我要不要用工具，提高資金使用效率？

而不是：我現在賺得太慢，有沒有辦法趕快翻倍？

看起來都叫使用槓桿，背後的狀態完全不同。

槓桿不會替你創造能力，它只會放大你原本有的東西。你有紀律，它放大紀律帶來的結果；你有優勢，它可能放大優勢；你沒有方法，它也會放大混亂；你本來容易失控，它就讓失控更快反映在帳戶裡。

使用以前，先認真問自己：我現在是真的已經有能力賺錢，所以開始思考怎麼提高資金效率？還是我只是嫌自己賺得太慢，所以想把速度加快？

這兩個問題看起來只差一點，最後卻可能把你帶到完全不同的地方。
